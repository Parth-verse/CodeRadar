# CodeRadar 🎯

> **"Scan your code. Spot the risks. Ship with confidence."**

CodeRadar is an AI-powered codebase health and intelligence platform. It combines **deterministic static analysis** (secret scanning, code smells, AST coupling, package audits) with **meaningful Google Gemini reasoning** (root-cause diagnosis, execution flow mapping, new developer onboarding, and targeted test generation).

---

## 🚀 10-Step Hackathon Demo Script

1. **Open Landing Page**: Launch `http://localhost:5173`. Notice the developer-first theme, clean cards, and "Deterministic analysis + Gemini reasoning" architecture.
2. **Launch 1-Click Demo**: Click **"Try Demo"** (or click **"Scan a Repository"** and select **"Try Demo Repo"**).
   - CodeRadar instantly ingests the multi-file `pulsecart/platform-core` e-commerce repository.
3. **Inspect CodeRadar Health Score**:
   - Notice the prominent heuristic score: **71 / 100** ("Needs Attention").
   - Review category scores: Bugs, Security, Quality, Testing, Dependencies, Architecture.
4. **Interact with the Repository Radar**:
   - Click the **"Security"** or **"Testing"** spoke on the hexagonal radar chart.
   - The UI immediately filters and presents the relevant findings.
5. **Inspect a Critical Finding (Credential Leak & Masking)**:
   - Click **"Potential hardcoded API credential detected"** in `src/config/firebase.js:7`.
   - Notice the raw key is safely masked: `AIzaSy************`.
   - Read the Gemini Analysis: explains the root cause and provides the exact environment variable replacement.
6. **Explore Architecture & Execution Flow**:
   - Navigate to **Architecture** tab.
   - Click `src/services/authService.js` to see its upstream imports and downstream consumers.
   - Click **"Explain: User Login Flow"**: Gemini traces the full execution chain from React view to Express API and highlights error-swallowing risks.
7. **Evaluate Testing Health**:
   - Navigate to **Testing Health**.
   - See the tested vs missing scenario matrix (22% coverage, 7 missing edge cases).
   - View the targeted test suite generated by Gemini ready to cover timeout and 401 exceptions.
8. **Investigate a Production Incident**:
   - Navigate to **Bug Investigator**.
   - Click a preset incident (*"Authentication Silent Failure"*).
   - Gemini correlates the stack trace with repository context and identifies the swallowed exception in `authService.js:23`.
9. **Simulate a Fix & Trigger Rescan**:
   - In the finding detail panel, click **"Simulate Fix & Resolve"** for the Firebase API key and `.gitignore`.
   - Click the **"Rescan"** button in the top navigation bar.
   - Watch the score jump: **71 / 100 → 79 / 100 (+8 points!)**.
   - Review the before/after delta banner celebrating resolved security findings.
10. **Ask CodeRadar (Repository-Aware Assistant)**:
    - Navigate to **Ask CodeRadar**.
    - Click quick questions: *"What does this project do?"*, *"Where is authentication handled?"*, or *"What should I fix first?"*.
    - Receive answers referencing real repository files with clickable citations.

## 🛠 Tech Stack

- **Frontend**: React 18, Vite 8, Tailwind CSS v4, Lucide React icons, Custom Hexagonal SVG Radar Chart.
- **Backend**: Node.js, Express, Multer (ZIP uploads), AdmZip, Axios.
- **AI Engine**: Google GenAI SDK (`@google/generative-ai`) powered by **Gemini 1.5 Flash**. Includes robust contextual fallback engine ensuring instant, 100% reliable evaluation even without internet or API keys.

## 🏃‍♂️ Getting Started

### 1. Start the Backend (Port 5000)
```bash
cd backend
npm install
npm start
```

### 2. Start the Frontend (Port 5173)
```bash
cd frontend
npm install
npm run dev
```

Visit **`http://localhost:5173`** in your browser.

### 3. Optional: Set Your Gemini API Key
You can add your key in `backend/.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
Or open **Settings** inside the CodeRadar UI and paste your key.

## 🔒 Security Best Practices
- Sensitive values detected during scanning are masked before rendering in the UI.
- No API keys or repository secrets are committed to version control.
